# [Thực hành] Sử dụng CSS

Mở `index.html` trong trình duyệt để xem kết quả.

- Quy tắc `h1` đặt màu xanh, font Tahoma và cỡ chữ 200%.
- Quy tắc `p` đặt màu đỏ, font Arial, cỡ chữ 120%, viền xám 1px và padding 10px.
- Selector `#element1` ghi đè màu của riêng đoạn văn có id tương ứng thành xanh.

CSS nằm trong `styles.css` và được liên kết từ HTML.
