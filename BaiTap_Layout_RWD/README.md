# [Bài tập] Tạo layout với RWD

Mở `index.html` trong trình duyệt để xem trang tạp chí du lịch được xây dựng bằng các khối `div` và CSS.

- Màn hình rộng: nội dung chính và sidebar gợi ý nằm cạnh nhau; bài viết xếp thành ba cột.
- Màn hình vừa: sidebar gợi ý chuyển xuống dưới; danh sách bài viết còn hai cột.
- Điện thoại: các khối xếp thành một cột và thanh điều hướng có thể cuộn ngang.

Ảnh minh họa được vẽ bằng CSS nên không cần tải thêm tài nguyên. Các breakpoint responsive được khai báo trong `styles.css`.
