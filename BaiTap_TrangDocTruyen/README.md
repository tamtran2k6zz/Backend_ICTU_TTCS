# [Bài tập] Tạo trang đọc truyện ngắn

Mở `index.html` trong trình duyệt để đọc ba truyện ngắn. Mục lục dùng liên kết neo đến từng phần; ảnh bìa là SVG cục bộ; CSS được nhúng bằng file `styles.css`.

Trang thực hành tiêu đề căn giữa, khung mục lục có viền/nền/padding, hiệu ứng hover và focus cho liên kết, cùng căn lề, thụt đầu dòng và giãn dòng cho nội dung truyện. Bố cục chuyển sang một cột trên màn hình nhỏ.
