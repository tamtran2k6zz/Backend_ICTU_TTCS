# Customer Management MVC

Scaffold Maven WAR cho bài thực hành MVC, tương thích Tomcat 10.1+ và Jakarta EE 10. Bao gồm cấu hình Maven/Web, các khung Model–Service–Controller và các JSP view rỗng có chú thích để tiếp tục hoàn thiện.

## Đóng gói

```sh
mvn clean package
```

Triển khai `target/customer-management.war` lên Tomcat 10.1+. Điểm vào ứng dụng được ánh xạ tại `/customers`.
