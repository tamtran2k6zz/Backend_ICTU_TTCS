# [Thực hành] Sử dụng Box Model

Mở `index.html` trong trình duyệt để xem ví dụ về bốn thành phần của CSS box model.

- Khung `.boxmodel` có chiều rộng tối đa 800px, viền 10px nhiều màu, nền xanh nhạt và padding 10px; `margin: auto` căn giữa khung.
- Mỗi đoạn văn có viền chấm và padding 10px.
- Ba đoạn lần lượt có `margin-bottom` là 20px, 40px và 60px để so sánh khoảng cách ngoài viền.

Các quy tắc CSS nằm trong `styles.css` để dễ chỉnh sửa và quan sát kết quả.
