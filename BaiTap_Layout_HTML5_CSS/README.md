# [Bài tập] Tạo layout với các thẻ HTML5 và CSS

Mở `index.html` trong trình duyệt để xem trang mẫu Góc sống xanh. Bố cục sử dụng `header` cho thương hiệu, `nav` cho điều hướng, `main` chứa vùng nội dung, `section` chia khu vực, `article` cho bài viết, `aside` cho thông tin bên lề và `footer` cho chân trang.

Các quy tắc bố cục và màu sắc được đặt trong `styles.css`. Layout dùng CSS Grid và chuyển sang một cột trên màn hình nhỏ.
