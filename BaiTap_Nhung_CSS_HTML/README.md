# [Bài tập] Nhúng CSS vào trang HTML

Mỗi trang có một tiêu đề và một đoạn văn; màu chữ được đặt bằng một cách nhúng CSS khác nhau:

- `inline-style.html`: thuộc tính `style` trực tiếp trên từng phần tử.
- `internal-style.html`: quy tắc CSS trong thẻ `<style>` ở phần `<head>`.
- `external-style.html`: liên kết đến `external-style.css`.

Mở từng file HTML trong trình duyệt để so sánh.
