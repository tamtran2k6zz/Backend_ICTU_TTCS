# [Thực hành] Sử dụng Bootstrap xây dựng form đăng nhập

Mở `index.html` trong trình duyệt (cần kết nối Internet để tải Bootstrap 5.3.8 từ jsDelivr). Form dùng lưới, utilities, input, checkbox và button của Bootstrap; phần `styles.css` tùy chỉnh giao diện và breakpoint.

Nút hiện/ẩn mật khẩu và kiểm tra tính hợp lệ phía trình duyệt hoạt động ở `app.js`. Đây là giao diện minh họa: thông tin đăng nhập không được gửi đến máy chủ, và nút Google chưa kết nối OAuth.

Bootstrap CDN và mã SRI theo [hướng dẫn chính thức](https://getbootstrap.com/docs/5.3/getting-started/introduction/). Logo SVG được lưu cục bộ trong `bootstrap-mark.svg`.
