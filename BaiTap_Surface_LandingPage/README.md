# Surface landing page

Open `index.html` in a browser. The page uses Bootstrap 5.3.8 components and responsive grid classes, plus a small custom stylesheet for Surface-inspired colors and imagery. Bootstrap and Microsoft-hosted product images load from their official CDNs, so an Internet connection is required.

The CodeGym offline ZIP linked in the assignment currently returns 404. The page uses product imagery and copy from Microsoft's live Surface page instead.
