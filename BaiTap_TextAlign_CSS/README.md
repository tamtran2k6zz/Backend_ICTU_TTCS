# Minh họa thuộc tính `text-align` trong CSS

Mở `index.html` trong trình duyệt để xem bốn cách căn chỉnh văn bản phổ biến:

- `left`: căn trái.
- `right`: căn phải.
- `center`: căn giữa.
- `justify`: căn đều hai lề.

Mỗi ví dụ có vùng xem trước và đoạn CSS tương ứng. Trang dùng stylesheet ngoài `styles.css` và tự chuyển thành một cột trên màn hình nhỏ.
