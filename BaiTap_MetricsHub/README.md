# MetricsHub — Responsive dashboard

Mở `metricshub_ui/index.html` bằng trình duyệt để xem dashboard. File `metricshub_ui/style.css` chứa phần trình bày tùy chỉnh; Bootstrap CSS được tải từ CDN. Xem `layout_strategy.md` để biết vai trò từng cách dàn trang và `ai_prompt_log.md` để xem prompt log.

Gói nộp bài: `metricshub_submission.zip`.
